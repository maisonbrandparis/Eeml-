# Les Enfants de l'École Marguerite Long

Site de l'association de parents d'élèves de l'école Marguerite Long, Paris 17e.
Élections des représentants de parents d'élèves, vendredi 9 octobre 2026.

## Contenu

- `index.html` : le site complet, un seul fichier, sans dépendance ni build
- La photo de l école est intégrée directement dans `index.html`, au format WebP encodé en base64

## Mise en ligne

Site statique. Aucune commande de build, aucun dossier de sortie.
Sur Vercel, laisser les réglages par défaut, Framework Preset « Other ».

## À mettre à jour

- Les six candidats de la liste, section 5, cherchez la classe CSS `trou`
- Le compte à rebours se calcule tout seul à partir du 9 octobre 2026
